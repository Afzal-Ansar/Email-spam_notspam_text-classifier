📨 Spam vs. Not Spam Classifier using Bag of Words
Made by: Afzal Ansari

This project is a classic binary text classification model that distinguishes between spam and non-spam (ham) messages using the Bag of Words technique and scikit-learn.

🚀 Features
🔤 Text preprocessing (lowercasing, punctuation removal, etc.)

🧠 Vectorization using Bag of Words

🧪 Train/Test Split for model evaluation

📈 Accuracy and performance metrics

✅ Lightweight and beginner-friendly NLP project

📁 Dataset
The dataset used consists of labeled SMS messages, where each entry is either:

spam

ham (not spam)

🛠️ Tech Stack
Python

Jupyter Notebook

Pandas, Numpy

Scikit-learn

NLTK / Regex (optional for preprocessing)
